# User Stories

## Account & Onboarding

- As a user, I want to create an account so that my wellness data is saved and private to me.
- As a new user, I want to enter my basic information during onboarding so that the app can personalize estimates and progress tracking.
- As a user, I want to set my target weight and weekly exercise goal so that I can track my progress toward them.
- As a user, I want my initial weight from onboarding to become my first weight entry so that I do not need to enter it twice.
- As a user, I want to update my profile and goals later if they change.

## Weight Tracking

- As a user, I want to log my weight whenever I measure it so that I can track changes over time.
- As a user, I want to see my weight history and trend so that I can focus on long-term progress rather than individual measurements.
- As a user, I want to see my progress toward my target weight.
- As a user, I want to edit or delete a weight entry if I entered something incorrectly.

## Meal Tracking

- As a user, I want to log a meal as breakfast, lunch, dinner, snack, or other so that my meals are organized.
- As a user, I want to describe a meal using text, a photo, or both so that I can log food without manually entering every ingredient.
- As a user, I want AI to identify the main components of my meal and estimate their calories so that I can get useful nutritional information with little effort.
- As a user, I want to see both the estimated calories for individual meal components and the estimated total calories.
- As a user, I want to review and edit AI-generated information before saving it so that I stay in control of my data.
- As a user, I want to indicate whether I ate at home, at a restaurant, or somewhere else so that I can understand my eating habits.
- As a user, I want to optionally record the restaurant name when eating out.
- As a user, I want to edit or delete previously logged meals.

## Exercise Tracking

- As a user, I want to log an exercise session with its activity, duration, and intensity so that I can track how active I have been.
- As a user, I want to choose from common activities or add my own activity so that I am not limited to a predefined list.
- As a user, I want the app to estimate calories burned using my activity and profile information so that I do not need to calculate them myself.
- As a user, I want to see my exercise history, total exercise time, and number of sessions.
- As a user, I want to edit or delete an exercise entry.

## Dashboard & Calendar

- As a user, I want to switch between weekly and monthly dashboard views so that I can understand both recent activity and longer-term patterns.
- As a user, I want to see summaries of my weight, meals, restaurant visits, and exercise so that I can quickly understand my recent habits.
- As a user, I want to open dashboard summaries to see the entries behind them.
- As a user, I want to see my tracked activity on a calendar so that I can understand what happened on each day.
- As a user, I want to select a calendar day and see all entries recorded on that date.

## Goals

- As a user, I want to set a target weight so that I can see my progress toward it.
- As a user, I want to set a weekly exercise goal so that I have a simple activity target to work toward.

## Garden

- As a user, I want my exercise to contribute to a virtual garden so that staying active creates visible progress.
- As a user, I want every 25 accumulated minutes of exercise to grow a new plant.
- As a user, I want leftover exercise minutes to carry over toward the next plant so that all of my activity contributes to progress.
- As a user, I want my garden progress to remain even when I miss days so that the feature feels encouraging rather than punishing.

## Empty States

When there is not enough data to display a chart, statistic, calendar entry, or garden progress, the app should show a helpful empty state instead of an empty visualization or a screen filled with zeros.

Empty states should guide the user toward the relevant first action, such as logging their first weight, meal, or exercise session.
